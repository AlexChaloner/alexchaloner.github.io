Interactive experiments

Flow Matching Diagrams

Here, diffusion predicts noise, which the sampler uses to work out how to move. Flow matching learns that motion directly. Let’s build the intuition with handwritten digits.

These are recorded teaching examples. The checkpoints have not been established as converged models, so differences between these runs do not establish which method learns faster. Position in the two-dimensional map is not a measure of digit quality; inspect the images too.

These teaching models generate full 32 × 32 images, starting from six of the exact noise samples above. Every state is mapped through the same frozen features and PCA axes. The training checkpoint changes the teaching model, never the coordinate system.

Diagram 2

Zero to Five

Digit Generator again, with zeros in place of noise and fives as the targets. Both 32 × 32 models learn the same zero–five pairs. One predicts the source zero, then derives velocity as (current image − predicted source) / t; flow matching predicts velocity directly.

Replacing Gaussian noise with digits makes this a generalized denoising experiment, rather than standard Gaussian diffusion. Neither model gets the source zero as an extra conditioning input. Dividing by t amplifies source-prediction errors near the start; these short runs are sensitive to the sampling step size.
